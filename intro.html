1Easy Shop and POS System гэж юу вэ?

Easy Shop and POS System бол Монголын дэлгүүр, цахим худалдаанд зориулсан иж бүрэн цахим худалдаа, касс, ачаа тээврийн платформ юм. Энэхүү систем нь зөвхөн "онлайн дэлгүүр" биш — онлайн худалдаа, дэлгүүрийн касс, ачаа тээвэр, хүргэлтийн менежмент, олон төрлийн төлбөрийн систем, борлуулагчийн маркетплейс, тайлан аналитик зэргийг нэг дор багтаасан төрлийн загвар шийдэл юм.

Системийг дараах 4 төрлийн хэрэглэгч ашиглана:

🛍️

Худалдан авагч

  • Гар утас/веб-ээр бараа сонгоно
  • Утсаар бүртгүүлж, OTP-ээр баталгаажуулна
  • Хадгалсан хаягуудаа ашиглана
  • Захиалга, хүргэлт, төлбөрийг хянана
👨‍💼

Админ / Менежер

  • Бараа, захиалга, харилцагчийг удирдана
  • POS касс ашиглана
  • Тайлан гаргана, борлуулалт хянана
  • Банкны хуулга татаж тулгана
🛒

Кассын ажилтан

  • Дэлгүүр дотор POS-аар бараа худалдана
  • Бэлэн/карт/шилжүүлгээр төлбөр авна
  • Өдөр тутмын борлуулалт хянана
🚗

Хүргэлтийн жолооч

  • Тусгай линкээр нэвтэрнэ (нууц үг үгүй)
  • Хариуцсан захиалгуудаа харна
  • Хүргэгдсэн/амжилтгүй гэж тэмдэглэнэ

2Frontend — Худалдан авагчийн систем (React SPA)

Гар утас, таблет, компьютерт оновчтой ажиллах Progressive Web App (PWA). Утсандаа суулгах, оффлайн ажиллах боломжтой. React 19, TypeScript, Tailwind CSS, shadcn/ui дээр бүтээгдсэн.

🛒 Сагс ба төлбөр (CartPage, CheckoutPage)

Сагс: localStorage-д хадгалагдаж, browser хаагаад дахин нээхэд хадгалагдсан хэвээр байна. Бараа бүрийн тоо/устгах, ачааны төлбөр (урьдчилсан захиалгад жинд тулгуурлан) автомат тооцно.

Төлбөр (3 алхамт urсгал):

  1. Хүргэлт сонгох: Хүлээж авах эсвэл хүргүүлэх. Хүргүүлбэл дүүрэг → хороо → гэрийн хаяг сонгоно. Нэвтэрсэн хэрэглэгчид өмнө хадгалсан хаягаа ачаалж болно.
  2. Төлбөрийн арга: QPay / Банкны шилжүүлэг / Бонум / StorePay (тус бүр админаас асаах/унтраах боломжтой)
  3. Захиалга баталгаажуулах: Захиалгын дугаар, QR код, төлбөрийн заавар, нийт дүн

👤 Профайл (ProfilePage)

3 таб бүхий хэрэглэгчийн самбар:

  • Захиалгууд: Бүх захиалгуудын жагсаалт, статус, цуцалсныг ялгаж харна. Хүлээж авах/хүргүүлэх горимыг шууд солих боломж.
  • Хаягууд: Хадгалсан хүргэлтийн хаягууд, шинэ нэмэх, default тогтоох, устгах.
  • Профайл: Нэр өөрчлөх, утас өөрчлөх (OTP баталгаажуулалттай), и-мэйл өөрчлөх (и-мэйл OTP-тэй).

🔐 Нэвтрэлт (LoginPage)

Маш уян хатан нэвтрэлтийн систем — админаас аль аргыг асаахыг тохируулна:

  • Утасны дугаар + нууц үгээр
  • Утас + SMS OTP-ээр (нууц үг шаардлагагүй)
  • OTP-гүй шууд бүртгэл (тохиргооноос асаавал)
  • И-мэйл + нууц үгээр бүртгэл/нэвтрэлт
  • Google нэвтрэлт
  • Facebook нэвтрэлт
  • Нууц үг сэргээх — SMS эсвэл и-мэйлээр

Нэвтрэлт шаардлагагүй. Зөвхөн захиалгын дугаараар бүх төлвийг харна — захиалгын зүйл, төлбөрийн төлөв, хүргэлтийн хаяг, одоогийн статус, timeline.

🏪 Борлуулагчийн систем (ProductEntryPage)

Тусгай эрх өгсөн харилцагчид өөрсдийн бараагаа оруулах боломж:

  • Бараа үүсгэх/засах форм — нэр, ангилал, дэлгүүр, төрөл, үнэ, нөөц, жин, зургууд
  • Зургийг автоматаар 1000x1000 хүртэл багасгаж оруулна
  • Тухайн ачааны багцад хуваарилах
  • Дэлгүүрт харуулах/нуух, захиалга авах/зогсоох
  • Өөрийн оруулсан бараануудын жагсаалт, засварлах

🚗 Жолоочийн самбар (DriverPanelPage)

Жолоочид өөрийн URL-ээр (нэвтрэлтгүй) нэвтэрнэ. Хариуцсан хүргэлтийн багцууд, харилцагчийн утас/хаяг, хүргэгдсэн/амжилтгүй болгох товч, өнөөдрийн статистик.

🚢 Ачааны багц (Cargo Batches)

Урьдчилсан захиалгад зориулсан. Гаднаас ирэх бараа, ачааны багц бүрийн менежмент:

  • Ачааны багц үүсгэх — нэр, кг тутмын тариф, төлөв
  • Багц илгээгдсэн/ирсэн үед бүх холбогдох харилцагчид автомат SMS явна
  • Багц хаагдсан: шинэ захиалга авахгүй
  • Багцийн төлөв нь түүнтэй холбогдсон захиалга бүхэнд автоматаар тархана

5Захиалгын урсгал — 10 төлөв

Хүлээгдэж буй → Баталгаажсан → Ачаа тээвэрлэгдэж буй → Ачаа ирсэн → Авахад бэлэн → Хүргэгдэж буй → Хүргэгдсэн → Дуусгасан / Цуцалсан
  • Автомат цуцлалт: N хоног төлбөргүй захиалгыг cron-оор автоматаар цуцална
  • Автомат баталгаажуулалт: Төлбөр баталгаажмагц "pending → confirmed" руу шилжинэ
  • Олон нийтийн мөшгилт: Зөвхөн захиалгын дугаараар нэвтрэлтгүй харна

6Төлбөрийн интеграцууд (4 арга)

📱
QPay
Монголын банкуудтай нэгдсэн QR код. Хаан банк, Хас банк, Капитрон г.м. бүх апп-тай ажиллана. QR + deep link. Автомат шалгалт.
🏦
Банкны шилжүүлэг
Гар аргаар. Тохиргооноос дансны мэдээлэл харагдана. Админ банкны хуулгаар тулгана.
💳
Бонум
Дансаар суурьт тулсан "одоо ав, дараа төл" (BNPL). Бонум апп-аар үргэлжлүүлж төлөх follow-up link.
🏪
StorePay
Хэсэгчилсэн төлбөр (installment). Утасны дугаар шаардана. Өөр API боловч урсгал нь Бонумтай төстэй.

Webhook callback: Гурван үйлчилгээ бүгд төлбөр баталгаажсан үед бид рүү дуудна. Тэгээд захиалгын payment_status = paid болж автоматаар баталгаажна.

1What is Easy Shop and POS System?

Easy Shop and POS System is a comprehensive e-commerce and point-of-sale platform designed specifically for Mongolian retailers and online shops. It is not just an "online store" — it integrates online sales, in-store POS, cargo logistics, delivery management, multiple payment gateways, a seller marketplace, and reporting/analytics into one unified system.

The platform serves four types of users:

🛍️

Customers

  • Browse and order via web/mobile
  • Register with phone + OTP
  • Save and reuse addresses
  • Track orders, payments, deliveries
👨‍💼

Admins / Managers

  • Manage products, orders, customers
  • Use POS terminal
  • Generate reports, monitor sales
  • Reconcile bank statements
🛒

POS Cashiers

  • Sell in-store via POS terminal
  • Accept cash, card, bank transfer
  • Monitor daily sales
🚗

Delivery Drivers

  • Login via dedicated URL (no password)
  • View assigned orders
  • Mark deliveries as completed/failed

2Frontend — Customer System (React SPA)

A Progressive Web App (PWA) optimized for mobile, tablet, and desktop. Installable on mobile devices, works offline. Built with React 19, TypeScript, Tailwind CSS, and shadcn/ui.

  • Customizable hero section — title, subtitle, description, image (managed from admin)
  • Trust section featuring partner retailers with logos
  • Dynamic category grid — loaded from API, can be enabled/disabled
  • Featured products with automatically calculated discounts
  • New / Pre-order product sections
  • Recently viewed products carousel — persisted in localStorage
  • Primary CTAs: "View All Items", "Pre-order", "In Stock Items"

🛍️ All Items Page

  • 60 products per page, paginated
  • Advanced filters: Product type (ready/preorder), Category, Shop, Discount only, New only
  • Sort: Popular (by rating × reviews), Price ascending, Price descending
  • Full-text search
  • Bottom-sheet filter drawer on mobile

📦 Product Detail Page

🛒 Cart & Checkout

Cart: Persisted in localStorage — closing and reopening the browser keeps items. Per-item quantity/remove, automatic cargo fee calculation based on weight (for preorder items).

Checkout (3-step flow):

  1. Choose fulfillment: Pickup or Delivery. For delivery: district → khoroo → address. Logged-in users can load saved addresses.

3-tab customer dashboard:

  • Orders: Full order list with status, cancelled orders visually distinguished. Switch pickup/delivery inline.

🔐 Login Page

Extremely flexible authentication — admin chooses which methods to enable:

🛒 Order Tracking

No login required. Just enter the order number to see all details — items, payment status, delivery address, current status, and full timeline.

5Order Workflow — 10 Statuses

Pending → Confirmed → Cargo Shipping → Cargo Arrived → Ready Pickup → Delivering → Delivered → Completed / Cancelled
  • Auto-cancel: Orders unpaid after N days are auto-cancelled by cron
  • Auto-confirm: Once payment is verified, status moves from pending → confirmed automatically
  • Public tracking: Customers can check status by order number alone, no login

6Payment Integrations (4 methods)

📱
QPay
Mongolia's unified QR payment standard. Works with Khan Bank, Xacbank, Capitron, and all major banking apps. QR + deep link. Automatic verification.
🏦
Bank Transfer
Manual transfer. Account info shown from settings. Admin reconciles via bank statement import.
💳
Bonum
Account-based "buy now, pay later" (BNPL). Returns a follow-up link for customers to complete payment in the Bonum app.
🏪
StorePay
Installment-based payment. Requires customer mobile number. Different API from Bonum but similar flow.

Webhook callbacks: All three providers notify us via webhook when payment is confirmed. The order's payment_status is automatically updated to paid.
